## MVS-T Demand Waterfall

a web application built to visualize the demand waterfall with the sales order and forecast data for mvs-t OF department

### tech stack

- nextjs (framework)
- supabase (database)
- handsontable (library)

## Usage

1. upload the files by clicking hte upload button
2. the files must be .csv file
3. in editing mode, left click on a date to change the forecast load in date, right click to delete that period records
4. use checkboxes to filter by platforms
